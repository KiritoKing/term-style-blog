# Community code of conduct

Be respectful and discuss the work in good faith. This applies to Issues, pull requests, reviews and other project spaces.

- Welcome people with different backgrounds and experience levels.
- Give specific, constructive feedback; disagree without personal attacks.
- Do not harass, threaten, discriminate, post sexualized content or publish private information without consent.
- Do not spam discussions or repeatedly ignore maintainer requests to stop disruptive behavior.

Maintainers may edit or remove inappropriate content, lock discussions, or restrict participation according to the severity and repetition of the behavior. They should explain the action when doing so does not expose private information.

For concerns that can be reported safely in public, contact the maintainer in the affected discussion. For harassment or sensitive personal information, use GitHub's **Report abuse** function on the relevant content; do not repost it in an Issue. Security vulnerabilities belong in the private reporting channel described in [SECURITY](SECURITY.md).

中文：尊重参与者，围绕事实和代码讨论。禁止骚扰、歧视、威胁、泄露隐私和刷屏。维护者可按情节删除内容或限制参与；敏感投诉使用 GitHub 的举报功能，避免二次公开个人信息。
