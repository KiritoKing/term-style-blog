## 为什么

当前博客正文缺少“目录（Table of Contents）”能力：读者在长文章中难以快速定位章节与回跳，尤其在终端风格布局下，滚动与定位成本更高。已有参考模板项目实现了目录的样式与交互，本变更用于在当前项目中补齐同等能力并保持视觉一致。

## 变更内容

- 在博客文章页渲染正文目录（TOC），目录信息直接从文章 content 中提取（基于 Markdown headings）。
- 目录的结构、样式与交互对齐参考项目 `/reference/ref-template-new`，确保视觉一致。
- 目录应与现有 Astro 静态渲染优先策略兼容：默认静态生成目录结构，仅在必要处引入最小客户端交互。

## 功能 (Capabilities)

### 新增功能

- `blog-toc`: 从博客文章内容中提取标题层级，生成并渲染与参考项目一致的正文目录。

### 修改功能

- (无)

## 影响

- 文章页渲染层：博客详情页需要增加 TOC 的生成与渲染逻辑（预计影响 `src/pages/posts/[id].astro` 及相关布局/组件）。
- 内容解析层：需要在渲染 Markdown 内容时同步得到 headings 信息（或从已存在的 content API 中读取），并确保层级、slug/锚点与正文一致。
- 样式体系：需要新增或复用一组 TOC 样式，使其与参考项目保持一致，并与当前项目的全局样式不冲突。
