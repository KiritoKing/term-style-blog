## 新增需求

### 需求:文章详情页必须提供评论区
系统必须在文章详情页展示评论区，以便读者在阅读路径内完成评论与反应操作。

#### 场景:访问文章详情页
- **当** 用户访问任意文章详情页
- **那么** 页面必须在正文下方展示评论区区域

### 需求:评论区必须使用 giscus 并基于 GitHub Discussions 存储
系统必须使用 giscus 作为评论系统实现，且评论数据必须存储在指定 GitHub 仓库的 Discussions 中。

#### 场景:加载评论数据
- **当** 页面加载评论区
- **那么** 评论列表必须从 GitHub Discussions 中展示对应 discussion 的评论

### 需求:评论区必须只在文章页加载
系统必须仅在文章详情页加载 giscus 脚本与 iframe，禁止在首页、列表页、分类页、标签页与关于页加载该脚本。

#### 场景:访问非文章页面
- **当** 用户访问首页、列表页、分类页、标签页或关于页
- **那么** 页面禁止加载 giscus 脚本与 giscus iframe

### 需求:页面与 discussion 的映射必须稳定
系统必须使用稳定的映射方式将页面与 discussion 关联，禁止依赖易变的页面标题作为唯一映射依据。

#### 场景:路径映射
- **当** giscus 在文章详情页初始化
- **那么** 系统必须使用 pathname 作为映射方式以查找或创建对应 discussion
