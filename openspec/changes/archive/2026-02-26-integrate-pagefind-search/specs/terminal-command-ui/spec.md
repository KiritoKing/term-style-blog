## 修改需求

### 需求:终端必须支持基础内建命令集合
系统必须至少支持以下命令：`ls`、`dir`、`cd`、`pwd`、`cat`、`clear`、`echo`、`whoami`、`date`、`help`、`grep`。

#### 场景:清屏
- **当** 用户输入 `clear`
- **那么** 终端输出必须被清空

#### 场景:帮助信息
- **当** 用户输入 `help`
- **那么** 终端输出必须列出可用命令及简要说明

#### 场景:执行 grep 命令
- **当** 用户输入 `grep <query>`
- **那么** 终端输出必须提示正在执行 grep 搜索
- **那么** 页面必须跳转至 `/search?q=<query>`

#### 场景:grep 缺少参数
- **当** 用户输入 `grep` 且未提供查询内容
- **那么** 终端输出必须提示正确用法
