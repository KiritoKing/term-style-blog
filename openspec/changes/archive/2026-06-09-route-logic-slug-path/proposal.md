## 为什么

当前帖子详情与列表链接统一依赖 id 作为路径，无法体现更稳定的 slug 导航规则。需要优先使用 slug 作为路径，以提升 URL 可读性并减少 id 暴露。

## 变更内容

- 调整路由生成与链接构建逻辑，优先使用 slug 作为路径。
- 当页面没有 path（slug）时，回退使用 id 作为路径。

## 功能 (Capabilities)

### 新增功能

- `post-route-preference`: 统一帖子详情与列表链接的路径偏好规则。

### 修改功能

- `blog-post-pages`: 帖子详情与列表链接的路径生成规则从仅依赖 id 改为 slug 优先。

## 影响

- 帖子列表页链接生成逻辑
- 帖子详情页静态路径生成逻辑
- 依赖帖子元数据的路由拼接代码
