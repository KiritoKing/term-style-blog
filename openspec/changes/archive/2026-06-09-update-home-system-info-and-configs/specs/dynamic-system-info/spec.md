## ADDED Requirements

### Requirement: 首页系统信息基于浏览器真实数据
首页系统信息 MUST 从浏览器可获取的真实信息生成，且不依赖手工写死的数据。

#### Scenario: 浏览器信息可用
- **WHEN** 用户访问首页且浏览器提供基础信息
- **THEN** 系统信息区块展示来自浏览器的真实数据值

#### Scenario: 部分字段不可用
- **WHEN** 浏览器缺少某些系统字段
- **THEN** 系统信息区块为该字段展示可识别的回退值

### Requirement: 系统信息以 neofetch 风格呈现
系统信息区块 MUST 以“标签 + 值”的列表形式呈现，符合终端风格的信息展示习惯。

#### Scenario: 系统信息渲染
- **WHEN** 首页渲染系统信息区块
- **THEN** 每一行包含清晰的字段标签与对应值

### Requirement: 系统信息仅对局部水合
系统信息的动态展示 MUST 限制在该区块局部水合，禁止将整页切换为客户端渲染。

#### Scenario: 水合范围
- **WHEN** 首页加载完成
- **THEN** 只有系统信息区块需要客户端 JS 执行
