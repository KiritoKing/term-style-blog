# Design

Run a frozen pre-fix corpus independently of the mutable worktree. Discover routes from generated HTML rather than a handpicked URL list. Record redirects, rendered pages, viewport coverage, screenshot locations, model assertion failures, console errors and container geometry separately.

Document width alone is insufficient when ancestors hide overflow. Inspect content and terminal container scroll extents and child bounds; intentional inner code/table scrollers remain allowed. Do not fix overflow by clipping the whole page.

Midscene receives only the approved blog-rendering pages through the configured provider after authorization. Local geometry/screenshot checks continue independently when model access is unavailable; an unavailable model is not a visual pass. Midscene failures require screenshot review because decorative terminal elements can be misclassified.

Tests precede fixes: missing/blank/placeholder category for both statuses, valid categories preserved, real long encoded Unicode route overflow, article rich-element sizing. The final sweep binds the exact code commit and content fingerprint and must be rerun after rendering changes.

For a localized post-audit correction, preserve the complete inventory audit and rerun visual checks for every affected route plus full deterministic route/geometry checks. Record the exact diff establishing that unaffected pages retain their rendered behavior; do not silently reuse evidence across unbounded layout changes.
