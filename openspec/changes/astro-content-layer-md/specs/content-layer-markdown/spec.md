## 新增需求

### 需求:博客内容层模型
系统必须在 Astro content layer 中定义博客集合与字段约束，并生成可用于构建期查询的类型安全 API。

#### 场景:构建期内容索引
- **当** 站点进行构建
- **那么** 内容层必须产出可查询的博客集合索引与类型定义

### 需求:Markdown 内容存储
系统必须将所有博客文章以 Markdown 文件存储在约定的内容目录中，并由内容层统一读取。

#### 场景:新增文章
- **当** 新增一篇 Markdown 博客文章
- **那么** 内容层必须在构建时读取并纳入博客集合
