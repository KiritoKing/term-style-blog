# Design

Preserve default false/manual for forks/unconfigured deployments. Authorized installation opts into true/automatic. Before promotion, authenticated requests must prove the expected framework/content/manifest identity and every generated HTML page, as well as robots indexing policy. Each HTML page carries a deterministic identity attribute; publication.json inventories routes. Secrets are injected only into requests for the exact Pages deployment host; redirects cannot forward secrets. Public production domain checks send no Access secrets. Production rebuilds use the same immutable input, serialize uploads, and recheck both branch tips. On failed post-promotion acceptance, restore the prior production deployment if the failed candidate remains current. Publish evidence must include immutable source IDs and real save-to-site trace.
