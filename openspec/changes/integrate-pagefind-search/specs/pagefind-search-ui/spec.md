## 新增需求

### 需求:站点必须提供基于 grep 交互的搜索页面
系统必须在 `/search` 页面提供 grep 风格的搜索交互，并使用 Pagefind 作为底层索引与查询实现。

#### 场景:访问搜索页面
- **当** 用户访问 `/search`
- **那么** 页面必须渲染 grep 风格的搜索输入与结果区域
- **那么** 页面必须以 Pagefind 索引作为数据来源

### 需求:搜索结果必须以 grep 输出格式展示
系统必须将搜索结果以 grep 风格的行式输出展示，包含文件路径与内容片段。

#### 场景:展示 grep 输出
- **当** 搜索命中结果
- **那么** 每条结果必须以 `path:excerpt` 形式展示
- **那么** 搜索页面必须显示执行命令头信息（例如 `$ grep -n "<query>" ~/posts/*.md`）

### 需求:搜索界面必须适配终端风格视觉
系统必须确保搜索页面使用终端字体与现有终端主题色彩，使搜索输入区与结果列表与终端 UI 风格一致。

#### 场景:终端风格一致性
- **当** 搜索页面渲染完成
- **那么** 搜索输入区与结果列表必须使用终端字体样式
- **那么** 搜索页面的前景与背景颜色必须与终端主题保持一致
