## 为什么

当前首页系统信息与侧栏/关于页数据偏静态，缺少可配置与真实设备展示能力，影响终端风格的拟真体验与可维护性。将系统信息改为基于浏览器真实数据并配置化可提升一致性与可扩展性。

## 变更内容

- 首页系统信息从浏览器真实信息提取，呈现接近 neofetch 的展示效果
- 侧栏 network 改为 array<config> 的配置方式，支持图标、文案、链接
- about 的数据支持配置化管理

## 功能 (Capabilities)

### 新增功能
- `dynamic-system-info`: 基于浏览器数据生成首页系统信息展示
- `configurable-network-links`: 侧栏网络信息支持可配置数组并渲染图标/文案/链接
- `configurable-about-data`: about 内容通过配置数据驱动展示

## 影响

- 首页系统信息渲染逻辑与数据来源
- 侧栏 network 展示组件与数据结构
- about 页面/组件的数据来源与渲染结构
