## 新增需求

### 需求:about 页面数据配置化
about 页面必须从统一的配置数据读取展示内容，禁止在页面内硬编码数据列表。

#### 场景:读取配置数据
- **当** about 页面渲染
- **那么** 页面展示内容来自配置数据源

### 需求:关于页技能列表由配置驱动
about 的技能列表必须完全由配置数组驱动，展示顺序与配置一致。

#### 场景:渲染技能列表
- **当** 配置包含多个技能项
- **那么** about 页面按配置顺序渲染技能项

### 需求:关于页基础信息可配置
about 页面核心描述信息必须可通过配置数据进行调整。

#### 场景:更新描述信息
- **当** 配置中的描述信息变更
- **那么** about 页面展示最新的描述内容
