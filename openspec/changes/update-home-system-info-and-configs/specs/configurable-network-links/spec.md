## 新增需求

### 需求:侧栏 network 使用配置数组驱动
侧栏 network 必须从配置数组渲染，每一项包含图标、文案与链接信息。

#### 场景:渲染配置数组
- **当** 配置数组包含多项 network 配置
- **那么** 侧栏按配置顺序渲染对应的图标、文案与链接

### 需求:network 链接可点击跳转
每一条 network 配置必须渲染为可点击的链接，并使用配置的跳转地址。

#### 场景:点击跳转
- **当** 用户点击 network 项
- **那么** 访问配置中指定的链接

### 需求:空配置不显示内容
当 network 配置数组为空时，侧栏不得展示空白列表内容。

#### 场景:无配置项
- **当** network 配置数组为空
- **那么** 侧栏不显示任何 network 列表项
