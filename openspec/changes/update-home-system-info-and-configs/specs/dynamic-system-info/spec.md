## 新增需求

### 需求:首页系统信息基于浏览器真实数据
首页系统信息必须从浏览器可获取的真实信息生成，且不依赖手工写死的数据。

#### 场景:浏览器信息可用
- **当** 用户访问首页且浏览器提供基础信息
- **那么** 系统信息区块展示来自浏览器的真实数据值

#### 场景:部分字段不可用
- **当** 浏览器缺少某些系统字段
- **那么** 系统信息区块为该字段展示可识别的回退值

### 需求:系统信息以 neofetch 风格呈现
系统信息区块必须以“标签 + 值”的列表形式呈现，符合终端风格的信息展示习惯。

#### 场景:系统信息渲染
- **当** 首页渲染系统信息区块
- **那么** 每一行包含清晰的字段标签与对应值

### 需求:系统信息仅对局部水合
系统信息的动态展示必须限制在该区块局部水合，禁止将整页切换为客户端渲染。

#### 场景:水合范围
- **当** 首页加载完成
- **那么** 只有系统信息区块需要客户端 JS 执行
