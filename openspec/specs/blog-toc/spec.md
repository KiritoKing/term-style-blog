# blog-toc

## Purpose

为博客详情页提供与正文一致的目录结构与终端风格展示。

## Requirements

### 需求:目录数据来自内容标题
系统必须从博客文章内容渲染产物中提取标题层级信息生成目录，不得依赖手工配置的目录数据。

#### 场景:文章包含多级标题
- **当** 文章内容包含多个标题层级
- **那么** 目录条目必须与标题文本一一对应，并按标题在正文中的出现顺序排列

### 需求:目录层级与正文一致
系统必须保留标题层级关系生成目录结构，目录的缩进层级必须与正文标题层级一致。

#### 场景:标题包含 h2 与 h3
- **当** 正文包含 h2 与其下的 h3 标题
- **那么** 目录中 h3 条目必须显示为 h2 的子级层级

### 需求:目录链接可跳转到正文
系统必须为每个目录条目生成指向正文标题锚点的链接，锚点必须与正文标题的 id 保持一致。

#### 场景:点击目录条目
- **当** 用户点击目录中的任意条目
- **那么** 浏览器必须跳转到正文对应标题的位置

### 需求:无标题时不渲染目录
系统必须在文章没有可用标题时隐藏目录区域。

#### 场景:文章仅包含段落文本
- **当** 正文不包含任何标题
- **那么** 页面不得渲染目录区域

### 需求:目录在宽屏下独立显示
为了提高屏效，目录在宽屏设备上必须显示在正文右侧的独立区域，而不是占据正文上方的垂直空间。

#### 场景:宽屏浏览
- **当** 视口宽度足以容纳侧边栏（如 xl 断点）
- **那么** 目录应显示在正文右侧，并保持 sticky 定位

#### 场景:窄屏浏览
- **当** 视口宽度较窄
- **那么** 目录可保留在正文上方或折叠

### 需求:目录样式与终端风格一致
系统必须使用现有终端风格样式类渲染目录容器与文本，目录容器必须包含 `pixel-panel` 样式并使用 `font-console` 字体体系。

#### 场景:目录渲染
- **当** 目录被渲染到页面
- **那么** 目录容器必须包含 `pixel-panel` 与 `font-console` 的类名
