# giscus-terminal-theme

## Purpose

确保 giscus 评论区的视觉与站点终端 UI 一致且可维护。

## Requirements

### 需求:评论区视觉必须与站点终端 UI 一致
系统必须为 giscus 评论区提供与站点“像素风 + 命令行 UI”一致的视觉样式，包括边框、底纹、字体、字号与强调色。

#### 场景:展示评论区
- **当** 评论区在文章详情页渲染
- **那么** 评论区整体必须呈现为与站点面板一致的终端模块风格

### 需求:主题样式必须可维护且可复用
系统必须以独立样式资源的形式提供 giscus 主题，禁止将大量零散样式直接内联在页面模板中。

#### 场景:维护主题
- **当** 需要调整评论区视觉细节
- **那么** 修改必须集中在主题样式资源中并可被版本控制

### 需求:主题样式必须托管在可信来源
系统必须确保 giscus 主题样式从可信域名加载，禁止引用不受控制的第三方 CSS 资源。

#### 场景:加载主题样式
- **当** giscus 初始化并加载自定义主题
- **那么** 主题样式必须来自站点自身构建产物或受信任的静态托管域名
