# list-pagination

## Purpose

定义列表分页切片、静态分页路由生成与分页导航展示规则。

## Requirements

### 需求:列表分页切片与页码
系统必须支持对任意列表数据进行分页切片，并基于页码参数确定当前页内容与总页数。

#### 场景:按页码获取当前页数据
- **当** 给定一个有序列表数据、每页条数与页码
- **那么** 系统返回该页对应的切片数据、总页数与规范化后的当前页码

#### 场景:页码越界处理
- **当** 请求页码小于 1 或大于总页数
- **那么** 系统必须将页码规范化到合法范围内，并返回对应页的数据

### 需求:分页路由与静态生成
系统必须为分页列表生成静态路由，使每一页都有可访问的 URL，并在构建期完成渲染。

#### 场景:文章列表分页路由
- **当** 文章列表存在超过每页条数的文章
- **那么** 系统生成多页路由，并且每一页展示正确的文章切片

#### 场景:标签/分类详情分页路由
- **当** 某个标签或分类下文章数量超过每页条数
- **那么** 系统为该 slug 生成多页路由，并且每一页展示正确的文章切片

### 需求:分页导航展示
系统必须在分页列表页面展示分页导航，并允许用户在页与页之间跳转。

#### 场景:展示上一页/下一页链接
- **当** 当前页不是第一页或最后一页
- **那么** 系统分别展示可用的上一页与下一页链接，并指向正确的分页 URL

#### 场景:展示页码链接
- **当** 总页数大于 1
- **那么** 系统展示页码链接集合，并高亮当前页码
