# taxonomy-browsing

## Purpose

定义分类与标签的派生规则、列表页与详情页的静态生成与过滤行为。

## Requirements

### 需求:分类列表必须由帖子集合派生
系统必须从帖子数据中派生分类集合，并对分类名进行小写归一化与去重。

#### 场景:派生分类列表
- **当** 系统生成 `/categories` 页面所需数据
- **那么** 分类集合必须由所有帖子 `category` 字段派生
- **那么** 分类集合必须去重并小写化

### 需求:标签列表必须由帖子集合派生
系统必须从帖子数据中派生标签集合，并对标签名进行小写归一化与去重。

#### 场景:派生标签列表
- **当** 系统生成 `/tags` 页面所需数据
- **那么** 标签集合必须由所有帖子 `tags` 字段派生
- **那么** 标签集合必须去重并小写化

### 需求:分类与标签列表页必须展示聚合项与数量
系统必须在 `/categories` 与 `/tags` 页面展示聚合项，并显示每个分类/标签对应的帖子数量。

#### 场景:浏览分类列表
- **当** 用户访问 `/categories`
- **那么** 页面必须列出全部分类项
- **那么** 每个分类项必须显示该分类下的帖子数量

#### 场景:浏览标签列表
- **当** 用户访问 `/tags`
- **那么** 页面必须列出全部标签项
- **那么** 每个标签项必须显示该标签下的帖子数量

### 需求:分类详情页必须静态生成并列出帖子
系统必须为每个分类生成静态详情页，并在 `/categories/<slug>` 列出该分类下的帖子条目。

#### 场景:分类静态路径生成
- **当** 站点执行静态构建
- **那么** 系统必须为每个分类 slug 生成对应的 `/categories/<slug>` 路由

#### 场景:浏览分类详情
- **当** 用户访问任意 `/categories/<slug>`
- **那么** 页面必须仅列出 category 匹配该 slug 的帖子

### 需求:标签详情页必须静态生成并列出帖子
系统必须为每个标签生成静态详情页，并在 `/tags/<slug>` 列出包含该标签的帖子条目。

#### 场景:标签静态路径生成
- **当** 站点执行静态构建
- **那么** 系统必须为每个标签 slug 生成对应的 `/tags/<slug>` 路由

#### 场景:浏览标签详情
- **当** 用户访问任意 `/tags/<slug>`
- **那么** 页面必须仅列出 tags 中包含该 slug 的帖子

### 需求:详情页必须提供返回列表页的入口
系统必须在分类与标签详情页提供返回 `/categories` 或 `/tags` 的导航入口。

#### 场景:从分类详情返回
- **当** 用户在分类详情页点击返回入口
- **那么** 页面必须跳转至 `/categories`

#### 场景:从标签详情返回
- **当** 用户在标签详情页点击返回入口
- **那么** 页面必须跳转至 `/tags`
