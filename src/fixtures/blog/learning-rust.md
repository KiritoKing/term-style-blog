# Learning Rust in 2026

Rust has become one of the most loved programming languages. Here's why you should consider learning it.

## Why Rust?

- Memory safety without garbage collection
- Zero-cost abstractions
- Concurrency without data races

## Getting Started

Install Rust using rustup:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## Your First Program

```rust
fn main() {
    println!("Hello, world!");
}
```

Compile and run:

```bash
rustc main.rs
./main
```

Happy coding!
